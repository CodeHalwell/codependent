# v0.4.5 — ACP connections and TUI follow-through

v0.4.5 makes ACP connection state truthful and finishes the model/result
workbench polish reported after v0.4.4.

## Fixes

- detects locally installed Junie, Cursor CLI, Cortex Code, Corust Agent, Crow
  CLI, Devin, and Stakpak ACP servers without weakening checksum enforcement
  for downloaded registry archives;
- adds opt-in detection for the community `agy-acp` bridge for Google
  Antigravity, with explicit third-party Terms-of-Service risk labeling and no
  automatic download or launch;
- persists locally discovered ACP suppliers such as Kimi Code through the same
  model-profile path as official-registry agents, so a selected Kimi model
  immediately appears in `/model`;
- treats an ACP `end_turn` with no assistant message as a failed, actionable
  run instead of displaying a misleading green `Completed` line;
- labels Amp's `low`/`medium`/`high`/`ultra` selector honestly as effort levels;
  Amp's ACP adapter chooses the underlying model and does not expose its model
  identity;
- prefers a newly staged model in the persistent bottom status strip so model
  selection updates immediately;
- widens the command palette and gives long command titles more room;
- compacts configured-model rows to identity plus provider, leaving location,
  cost, context, and readiness in the detail pane;
- makes the Council Results detail pane scroll with the mouse wheel in addition
  to Page Up/Page Down.

## Antigravity setup caveat

Google does not currently ship native Antigravity ACP. Codypendent recognizes
an explicitly installed `agy-acp`/`antigravity-acp` community bridge on
`PATH`. The bridge project warns that using third-party software with an
Antigravity OAuth account may violate Google's Terms of Service and may risk
account suspension. Review Google's terms and the bridge source before opting
in; Codypendent deliberately does not install it for you.
