# v0.4.4 — green-gate follow-up

v0.4.4 is the fully green follow-up to the v0.4.3 collaborative-workbench release. It contains the complete v0.4.3 feature set and corrects the final repository CI regressions found after publishing that tag.

## Fixes in this patch

- keeps the persistent status strip's width calculation Clippy-clean on the current stable Rust toolchain;
- reduces the governed-learning activation result size without changing its typed public behavior;
- removes redundant copies of optional learning expiry timestamps;
- makes the built-in registry idempotency test validate stable identities and counts instead of assuming the pre-council, pre-workflow 11-item catalogue.

## Included collaborative-workbench features

- guided first-run onboarding that only completes after a genuinely runnable model is configured;
- live provider and ACP model discovery, model removal, honest readiness, and actionable recovery cards;
- Codex, Claude Code, Kimi Code, Amp, GitHub Copilot CLI, Cline, and Mistral Vibe ACP support;
- a calmer responsive TUI with a persistent model/context/subagent strip, taller composer, improved pickers, copy/paste, and accessible cooked mode;
- durable agent councils with complete round reports, chair synthesis, stable result IDs, and a Council Results workbench;
- natural-language-accessible typed tools for council creation/runs/results, workflow creation/runs, Kanban tasks, and blackboard operations;
- governed, scoped learning capture with the `/journey` review workbench;
- migration 0024 and backward-compatible council/report persistence.

## Upgrade

```sh
codypendent update v0.4.4
```

Or use the installer:

```sh
curl -fsSL https://raw.githubusercontent.com/CodeHalwell/codypendent/main/install.sh | bash -s -- v0.4.4
```

Existing configuration, councils, memories, and learning records are retained. Cline still requires a valid Cline login; use the recovery card's Re-auth action when its ACP reports that authentication has expired.
