# v0.4.1 — clearer agents, quieter memory

This patch release focuses on the daily TUI experience and the reliability of
ACP-backed models.

## Highlights

- Bare ACP supplier rows in `/model` now open that agent's live model catalogue;
  concrete discovered models can then be selected and pinned normally.
- ACP failures surface their actionable nested reason instead of the generic
  `ACP prompt failed` message. In particular, an expired Cline login now tells
  the operator that re-authentication is required.
- The chat composer starts taller and grows further for wrapped drafts.
- A persistent two-row footer keeps the loaded model, context use/window, and
  active subagent count visible even while notices, recording, or approval
  controls occupy the action row.
- Council member and chair runs are first-class subagents in that telemetry,
  alongside durable workflow agent nodes.
- Automatic memory curation no longer stores generic greetings, completed-run
  summaries, changeset receipts, or opaque argument digests. Repeated failure
  records are normalized and deduplicated across volatile run IDs. The
  immutable chronicle still retains the underlying audit history.
- The Rust `agent-framework-*` runtime dependencies move together from 0.1.1 to
  0.2.0.

## Reliability

- Selecting a newly connected ACP model refreshes and stages its concrete model
  profile immediately.
- Model/provider catalogue scrolling, paging, Home/End navigation, responsive
  picker layout, and command-palette collision fixes remain covered by the full
  TUI suite.
- A macOS path-canonicalization assertion in the skill installer is now stable
  across `/var` and `/private/var` aliases.
