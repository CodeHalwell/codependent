# v0.4.0 — the wiring release

Codypendent v0.3.2 had an unusual shape: engines were built, tested and
documented, and the last wire connecting them to the model or the user was
missing. The [2026-08-11 product review](../reviews/2026-08-11-product-review.md)
found that pattern in all ten target areas. This release attaches those wires.

## The headline

**The model can finally see its own context.** The knowledge fabric assembled a
repository map, top-k skill cards and curated memories on every run — and
rendered them as a trace note the human read and the model never did. The
system prompt was one hardcoded sentence. The manifest now enters the prompt at
a single seam shared by the native path, the ACP path and continuations, so
retrieval, the memory pipeline and skills all became load-bearing at once.

Two consequences worth calling out: the shipped `rust.fix-ci` skill was
`status = "draft"`, which the retrieval hard-filter dropped silently — it is
active, and a red-then-green test now pins that a skill card is actually
disclosed. And skills are installable: a startup scan picks up
`<data_dir>/skills/` and `.codypendent/skills/`, plus `codypendent skill add`.

## By objective

**ACP model discovery.** The client received the agent's advertised models and
threw them away. It now captures `config_options`/`modes`/`auth_methods`,
persists one profile per discovered model (`id@version#model`), calls
`session/set_config_option` before prompting, lists them in the TUI picker, and
cancels gracefully instead of SIGKILL. Serve mode emitted non-spec
`session/update` payloads — Zed saw nothing until the final stop reason — and
now serializes the SDK's own schema types. MCP servers are forwarded into ACP
sessions.

**Model selection.** Curated `[[model]]` rows ship for every provider in the
catalog — Nebius first and complete, plus the frontier APIs, aggregators, local
runtimes, and speech/embedding models — merged with live `/models` discovery so
the picker shows context windows and prices, and still works offline or against
providers with no listing endpoint. A silent breakage is fixed: adding an Azure
OpenAI or extra-header provider wrote a bearer-auth profile that listed models
correctly and then 401'd on every run.

**Local models via Unsloth.** Browse the `unsloth` GGUF catalog, `models pull`
into Ollama with progress and auto-registration, and `finetune init` scaffolds a
QLoRA project that exports back to a model the picker can serve.

**DAG viewer.** Edges now travel on the wire, the TUI paints a layered DAG with
box-drawing connectors, VS Code renders an SVG graph, and `workflow.query` gives
the agent the same graph state the human sees. The remote-UI graph primitive was
dropping SDK-authored edges entirely.

**Kanban and backlog.** Repository-scoped boards on the blackboard substrate
(status/assignee/ordinal), client write commands, a board pane, and `task.*`
tools so an agent can turn a request into cards.

**Councils.** Fair-share dossiers so every member reaches the chair (dissent was
being truncated away alphabetically), run-from-TUI with streamed progress,
`--evidence` mode with read-only tools for file:line grounding, persisted
reports, and measured-only cost totals.

**Docs writer.** Documents can be created at all — there was no path, in any
client. Agents get `docs.*` tools attributed as `DocumentAuthor::Agent`, routed
through the collaboration-mode gate so org-scope edits land as reviewable
suggestions. `/update-docs` wires the staleness engine that existed but never
ran, and accepting one suggestion no longer strands the rest.

**Voice.** Push-to-talk capture → `PutArtifact` → transcription behind the
existing classification gate, and spoken replies, over OpenAI-compatible
`/audio/*` endpoints (Groq Whisper, OpenAI, DeepInfra, local servers).

**Retrieval.** Real embeddings behind the existing `Embedder` trait with
persisted vectors and an outbox drain; MCP tools are advertised top-k by
relevance once they exceed a threshold, instead of injecting every description
on every step.

**Chat stream and TUI.** The expanded tool cards and diff renderer existed but
no input could reach them — now clickable and keyboard-reachable. Composer
cursor editing, corrected wrap accounting (the measure and the draw disagreed,
so follow-mode could clip the newest line), display-width truncation, timestamps,
live `/theme`, and honest key-binding help.

**Runtime.** All returned tool calls execute instead of only the first,
mid-run compaction, retry with backoff on transient stream errors, and hidden
tool parameters are advertised.

## Security fixes found in review

- **Voice classification bypass**: the off-device gate trusted the client's
  claimed sensitivity while fetching bytes by id. Upload Secret audio, resend
  the id marked `Public`, and it reached a remote transcriber. It now reads the
  stored classification; an unreadable value fails closed.
- **Cross-repository document access**: scope was enforced only in the listing,
  so a known document id from another repository could be read and written.
  Every direct read and write is now gated, answering `NotFound` so foreign id
  space cannot be probed.
- **Skill install path traversal**: a package's `id` became its install
  directory unvalidated, so `../../.ssh` would have escaped the skills root.

## Data-loss fixes

- `models pull` serialized only `[[model]]`, silently deleting `[voice]`,
  `[transcription]`, `[speech]`, `[embedding]` and `[retrieval]` config.
- `task.update` replaced rather than merged, so renaming a card deleted its
  description.
- The docs sweep resolved every stored document against whichever repository was
  scanning, filing false staleness and overwriting other repositories' baselines.
- A recorder started by push-to-talk kept capturing after the TUI exited.

## Known gaps

Carried forward honestly rather than closed:

- The filesystem watcher is not armed; the code graph refreshes on git HEAD
  change instead, which removes the stale-for-days failure but not the
  edit-during-session one.
- Council member sessions are not archived after a run — the protocol has no
  end-session command.
- The remote-UI blackboard projection rides the existing `workflow-read`
  capability rather than a dedicated one.
- Phase 6/7 remainders (WASM runtime, hook engine, live measured routing) are
  unchanged.
