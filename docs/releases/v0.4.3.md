# v0.4.3 — guided setup, durable councils, and a calmer TUI

This patch release makes Codypendent easier to configure, easier to understand
while it is working, and safer to recover when an external ACP agent fails. It
also promotes councils and curated learning from experiments to durable,
reviewable product surfaces.

## Highlights

- A new first-run setup flow separates hosted APIs, local endpoints, and ACP
  coding agents. Setup does not call a profile ready until the host reloads it
  as runnable, and skipping clearly explains that agent runs remain unavailable.
- `/provider` now drills from an ACP supplier into its live model catalogue.
  `/model` stages concrete models, supports wheel/page/Home/End navigation, and
  retains the guarded deletion flow for user-configured profiles.
- The command palette, provider catalogue, model picker, council builder, and
  other modal surfaces are responsive at narrow and wide terminal sizes, with
  matching cooked-mode semantics and clearer selected-row contrast.
- The composer shows at least three text rows at normal terminal heights and
  grows with Unicode-aware wrapping. A persistent session strip keeps the
  model, mode, context, agent activity, permissions, worktree, cost, and
  integration health visible according to the available width.
- Transcript tool, diff, reasoning, learning, and failure rows are compact
  cards. ACP errors now identify the provider/model and failed phase, sanitize
  the cause, and offer relevant retry, re-authentication, model-choice, or
  disable actions instead of the generic `ACP prompt failed` message.

## Agent councils and coordinated work

- Councils are a shared first-class service used by the CLI, TUI, and agent
  runtime. A definition contains 2–8 configured model profiles, a role for each
  member, a chair, and 1–3 rounds.
- The seven-step TUI builder creates private, atomically persisted definitions.
  `/council` lists and runs them; `/council result <name-or-id>` reopens durable
  completed or partial results with stable attribution to every session/run.
- Member runs execute concurrently in independent read-only sessions. Reports,
  failures, measured usage, and the chair synthesis are persisted even when
  quorum or chair execution fails.
- Creating or running a council from an agent tool requires a fresh explicit
  approval. Member reports are framed as untrusted evidence before chair
  synthesis, and returned synthesis is likewise labeled before another model
  can consume it.
- Agents can now create or run validated workflows, query workflow state, post
  typed Blackboard evidence, and create/update/move/list repository Kanban
  tasks through repository-scoped, policy-evaluated tools. The corresponding
  TUI browsers support the same human-driven operations.

## Learning that stays reviewable

- `/journey` (or `J`) opens the new governed learning review surface. It shows
  compact facts and procedures with scope, confidence, state, provenance, and
  pin status; controls activate, reject, edit, pin, or permanently delete a
  selected record.
- Automatic capture is deliberately narrow: explicit user preferences or
  corrections and allow-listed local verification commands that actually
  succeeded. Greetings, generic completion messages, raw logs, temporary paths,
  tool output, URLs, and secret-shaped content do not become durable learning.
- Migration `0024_learning.sql` adds the curated learning ledger without
  rewriting legacy memory rows. Existing memory remains available separately.

## Copy, paste, mouse selection, and accessibility

- Browse transcript cards with `Alt-↑` / `Alt-↓`; `Alt-Enter` expands the
  focused card and `Alt-Y` copies its safe projection. Failure cards add
  `Alt-R` retry, `Alt-A` re-authentication guidance, `Alt-M` choose model, and
  `Alt-D` guarded disable.
- Council results use `y` / `copy` to copy the full chair synthesis. Interactive
  terminals use a bounded OSC 52 copy request; cooked mode prints a bounded,
  control-sanitized fallback when no terminal clipboard is available.
- Shift-drag remains terminal-native text selection: Codypendent does not turn
  it into a transcript click. Bracketed paste into text fields is multiline,
  control/bidi-sanitized, UTF-8 safe, and capped at 64 KiB.
- The splash waits for `Enter`, and `--accessible` / `--plain` exposes the same
  onboarding, picker, council, Journey, recovery, and confirmation controls as
  stable line-oriented commands.

## Install and upgrade

Prebuilt releases support Apple Silicon macOS, Intel macOS, and x86-64 Linux.
Windows remains unsupported because the daemon currently uses Unix sockets and
process semantics.

```bash
# Existing installation: inspect, then install this exact tag.
codypendent update --check
codypendent update v0.4.3

# Fresh/private-repository installation using an authenticated GitHub CLI.
gh api repos/CodeHalwell/codypendent/contents/install.sh \
  -H 'Accept: application/vnd.github.raw' | bash -s -- v0.4.3
```

The updater installs the Codypendent binaries and sealed UI runtime together.
It restarts an idle daemon on the new build; active runs are not killed and the
daemon upgrade waits until they finish or until the next launch. On first open,
the embedded migrator applies the additive learning migration automatically.
Existing model, auth, council, workflow, Blackboard, and session data is kept.

The release remains local-first, but an ACP process is a trusted vendor
executable running with the normal authority of your OS user. Codypendent's
approval UI is a cooperative ACP boundary, not an operating-system sandbox.

## Known issue

- Cline cannot complete a live request when its own login has expired. The new
  failure card reports this as an authentication problem and gives a direct
  re-authenticate-then-retry path; Codypendent never copies vendor credentials
  into its own key store.
