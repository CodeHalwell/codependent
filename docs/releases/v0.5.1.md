# v0.5.1 — consistency and release integrity

This patch release closes the final consistency issues found in the v0.5.0
review without changing its user-facing model, council, workflow, or ACP
contracts.

## Fixed

- Workflow runs now persist their server-derived owner in the same transaction
  as the run and node graph. Idempotent retries are principal-bound, so another
  local principal cannot collide with or adopt a run key.
- Every `models.toml` mutation now holds one cross-process advisory lock across
  read, edit, durable atomic replace, and directory sync. Concurrent TUI, CLI,
  ACP, and local-model additions no longer erase one another.
- A code-graph watcher overflow deferred by the rebuild cooldown now schedules
  and completes an authoritative rescan even when the repository becomes quiet.
- The built-in tool retrieval budget is spent only on discretionary tools;
  always-advertised safety tools no longer consume the top-k slots twice.
- Tagged and rolling release artifacts now wait for Rust formatting, Clippy,
  and the complete workspace test gate as well as the frontend gate.
- Upgrade documentation now reflects the current version.

## Correction to this note

An earlier revision of the line above claimed a "verified, immutable migration
history", and the upgrade section of the user guide was rewritten to match.
**That was wrong, and it replaced a correct warning.** The published builds
`v0.1.0-build.43`, `.44` and `.45` really do ship a different
`migrations/0003_phase2.sql` (sha256 `a5c81199c24b`) than every other release
including this one (`a29143289fa4`) — re-verified 2026-08-13 by hashing the file
at each tag. A database created by one of those three builds cannot be opened by
a later release: `sqlx` refuses to boot on a changed migration checksum. The
accurate warning is restored in
[`../cli-and-tui-user-guide.md`](../cli-and-tui-user-guide.md) §1 and the
incident is recorded in `migrations/README.md`.

## Upgrade

```bash
codypendent update v0.5.1
```

Or install directly:

```bash
curl -fsSL https://raw.githubusercontent.com/CodeHalwell/codypendent/main/install.sh | bash -s -- v0.5.1
```

The database migrations remain additive and existing sessions, model
configuration, councils, workflows, and learned records are preserved.
